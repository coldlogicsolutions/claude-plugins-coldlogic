# Pull requests

- Review runs locally: the built-in `/code-review` before every push. Never run `/code-review ultra` unless Derek asks for it. (Decided 2026-10-26.)
- Open every PR ready for review, never as a draft: the local review has already run. (Decided 2026-10-26.)
- After opening a PR, start `/loop` so CI failures and Derek's review comments get worked until the PR is green.
- Fix each finding, push, then reply to its thread naming the fixing commit and resolve it. If a finding is wrong, say so with evidence instead of complying.
- Stop to ask only when a finding is ambiguous or architecturally significant.
- Never merge from a session.
